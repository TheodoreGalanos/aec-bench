## Regional Benchmark Design Consequences

- Every task instance should carry a `region_or_authority_basis` field before generation hardening.
- Regional switches must change more than labels. They can change rainfall sources, load combinations, safety factors, accepted calculation method, approval artifact, and verifier logic.
- For gated standards, the benchmark should either provide the relevant criteria inside the task package or grade evidence/rationale without requiring memorized clause text.
- Meta-harness variants should be able to reconfigure a task across US, Australia/NZ, EU/UK, and owner/AHJ-specific overlays while preserving the same underlying physical scenario.
