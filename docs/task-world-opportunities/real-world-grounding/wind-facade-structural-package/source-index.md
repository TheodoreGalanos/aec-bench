# Wind Facade Structural Package Source Index

## Current Chain Confidence

Medium-high for workflow and component verification, but still not fixture-complete. The real chain should be:

wind climate/terrain/topography/importance -> design wind speed -> external/internal pressure coefficients -> facade zone/tributary area -> bracket/fixing reactions -> structural load combinations -> fixing/material/tolerance checks.

The latest public evidence materially improves the fixing side and the engineering-intake/output shape. Hilti's BBA certificate for EuroFox rainscreen support systems includes design responsibilities, wind-action basis, bracket-to-rail fixing constraints, anchor/substrate requirements, and bracket design resistance tables. Hilti's HRD-H anchor page and technical data sheets add anchor base materials, ETA/fire approvals, embedment, spacing, edge-distance, resistance/load, and installation evidence for fastening facade mounting brackets to concrete and masonry. EJOT's CROSSFIX public product pages, brochure, and ETA documents add an independent rainscreen substructure family with brackets, profiles, thermal separation, product variants, design-resistance categories, wall-bracket screw approvals, project-specific calculation responsibilities, and anchor/substrate verification requirements. Leviat/HALFEN HCW adds a curtain-wall anchoring route with product metadata, an example specification, edge-of-slab/top-of-slab/punched-window engineering intake forms, load and fallback geometry fields, concrete/code fields, custom-clip geometry fields, and a top-of-slab working-load datum. SFS/NVELOPE is now better grounded than an app-only source: its public sitemap/resource hub exposes direct NVELOPE system/product/download routes, the 2024 capability brochure documents Project Builder outputs, drawing-overlay outputs, bracket option tables, fixed/sliding point logic, and level-1/2/3 fixing responsibilities, and the extracted brochure text gives usable bracket size, zone-depth, slot, and product-code table fields for standard aluminium, NVF2F, and NH3 systems. The NH3 flyer also provides a limited load-vs-bracket-size chart with a 0-4 kN load axis and 0-300 mm bracket-size axis. The SFS resource hub also exposes NVELOPE installation guides and detail drawings: NV1/NV3/NH3/NVF2F guides record static-calculation dependency, bracket positioning, primary/secondary fixing roles, fixed/sliding point rules, pull-out-test boundaries, expansion gaps, datum/elevation setout, hanger counts, and dead/dynamic load responsibility, while rendered NV1 and NV3 detail drawings provide generic cladding views, a generic panel-module elevation, section details, window/corner details, adjustment tolerances, component legends, and cladding-zone/detail-location visuals. Direct SFS product-page and BBA-certificate capture now closes much of the public NVELOPE capacity-table gap: the NV, NH3, and NVF2F BBA product sheets expose bracket design-resistance tables, rail/profile geometry tables, BS EN 1991-1-4 wind-action basis, site pull-out-test responsibility, and the combined vertical/horizontal utilization rule, while the product pages expose attachment links and login boundaries for basket/catalogue behaviour. Direct SFS case-study capture now adds real-project evidence around the missing output chain: public case studies identify Project Builder design-service use, accurate wind-load calculations/pricing, detailed design, real cladding areas and panel weights, selected NV/NH3/NV1/NV3/NV4/NV5/NV6/NV7/NVF2F systems, bracket ranges, extra bracket counts, custom rails, pull-out tests, and downloadable project case-study PDFs, but still not the underlying Project Builder reports or utilization tables. Cascadia Clip now adds a North American cladding-attachment source family with public spacing-calculator workflow, RDH structural load-table design briefs for US and Canadian use, IAPMO UES evaluated allowable spacer loads, fastener mechanical data, z-girt/hat-track section data, and a rendered assembly layout guide showing clip spacing, rail orientation, substrate installation notes, and installation sequence. Direct inspection of the public Cascadia calculator implementation now exposes the app's field labels, option codes, query order, result endpoints, and a tested source-derived response tuple for R-value, U-value, and maximum wind load. A current Cascadia product-download and quote-form pass adds the public detail/source-pack boundary: the product hub exposes 3-part specifications, installation overviews, architectural detail PDFs/DWGs, adjustability details, BIM, current code/report/download inventory, and the Jotform quote request exposes project/status/logistics fields, area-by-area cladding square footage, clip/fastener/steel selections, product quantities, and adjustment shim/bracket options; this is still quote/detail evidence rather than a formal calculator spreadsheet, project submittal, or utilization chain. Fixfast now adds both app/request evidence and SPIDI product-pack evidence: the public UK facade-calculation article, support-system calculator, and calculation-request form expose project postcode/height, building plans/elevations, cladding area/weight/attachment, rail orientation/configuration, bracket material, cladding zone, substrate, upload/AutoCAD prompts, and project-specific calculation request fields, while SPIDI Max range/category pages and public brochures expose bracket length/material/product-code fields, fixed/sliding/drillscrew/anchor location diagrams, substrate-specific MechFix component schedules, and the returned output shape of static/dynamic load calculations, detailed calculations, schematic/assembly drawings, and materials/pricing schedules. Downer Designer and the Downer download centre add UK app-shaped and form-shaped routes for static and thermal calculations, optimized component/fixing configurations, integrated wind-load analysis to BS EN 1991-1-4 and UK National Annex, NBS specification, PDF reporting, downloadable manual/BBA-certificate inventory, rail-length/cantilever optimization, substrate-specific fields, and peak pull-out/shear fixing advice. Bluechip BICEP adds an Australia-facing ventilated-facade manual with adjustment formulas, fixed/floating-point behavior, project engineering input fields, and structural-engineer fixing responsibility. Clad-Sec adds UK site-checklist evidence for project-specific static calculations, dead-load fixed points, wind-restraint/sliding points, bracket centres, primary fixings, and setout drawings. The remaining high-risk gap is no longer "no non-Hilti corroboration" or "no public SFS capacity tables"; it is the lack of a public worked project calculation that connects an elevation, pressure zones, bracket layout, product selections, substrate, anchor capacities, and utilizations in one coherent package.

The latest Eurofox/Rainscreen Works pass partially reduces the worked-calculation shape gap. A public Eurofox catalogue includes a sample static-analysis page with input data, wind load, support system, profile length, cantilever, effective span, unit spacing, HPL panel type, wall weight, sliding-point checks, anchor-point checks, permissible bolt/rivet and dowel-force checks, moment/deflection diagrams, stress ratio, and several percent utilization outputs. Hilti Ireland's Eurofox page and the Williaam Cox/Rainscreen Works PDF also document real service outputs: static calculations, elevation drawings, installation plans, setting-out information, component schedules, material lists, and all fastening points. This is valuable public sample-calculation and output-contract evidence, but it is not a completed project submission with a real elevation, pressure-zone map, selected bracket schedule, anchor schedule, and final issued utilization chain.

The WPS exterior wall cladding panel system calculations now add a stronger public calculation-chain source. The 27-page PE/system calculation package covers decorative exterior panel assemblies, aluminium clips/rails/adjustable mounting brackets, backing options, ASCE 7-10/CBC/IBC wind, seismic, and gravity loads, connection spacing, tributary dead/wind loads by zone, connection summary tables, material properties, and screw allowable tension/shear values. This narrows the public worked-calculation gap more than a brochure or service page, but it is still a generic system calculation rather than a real project elevation, selected project bracket/anchor schedule, or issued project utilization report.

The Knight Wall Systems pass adds another North American cladding-attachment route with a sharper submittal and per-project engineering boundary. KWS public product pages and downloads expose MFI/THERMABRACKET system depth, rail orientation, spacing governed by design wind pressure, cladding weight, deflection requirements, and substrate type, project-specific engineering availability, guide details, guide specifications, and data-sheet inventory. The MFI guide specification records a structural-design-analysis submittal shape, manufacturer Professional Engineer project-specific calculations for bracket spacing, per-project maximum spacing/dead-load logic accounting for wall-anchor live/dead load, tension, pry, and shear, and fastener/embedment/pull-out requirements. The MFI D-Series data sheet adds bracket depth, adjustability, backing substrate, material, thickness, yield-stress, and cavity evidence, while the ANKIT data sheet adds thermal-isolated anchor/fastener installation routes and ultimate pull-out/tension values for wood, steel, concrete, and CMU plus spacing and edge-distance fields. KWS public case studies add real project/product-selection context, including Logan Airport Terminal E and University of Idaho WWAMI, but the route still does not expose an issued project calculation, selected anchor schedule, real pressure-zone elevation, or governing utilization package.

The Hohmann & Barnard pass adds a new North American engineered-support and load-table source family. The public HB RS EZclad product page states that the system is fully engineered to project conditions by H&B engineers, spans up to 100 inches before a midspan bracket connection, and includes structural connection, rail, engineering calculations, and shop drawings. The HB RS FLEXbracket product page records a stainless steel universal bracket ordered to suit insulation depth, accepts aluminum rail systems, supports vertical and horizontal rails, and is an adjustable engineered system. The public HB Rainscreen Brochure provides source-pack tables rather than only marketing text: it repeats the project-engineered calculation/shop-drawing boundary, says full calculations are provided based on rainscreen panel size and type, and gives FLEXbracket vertical/horizontal load tables for 30 psf wind, dead load up to 5 psf, bracket spacing such as 16x36 and 24x32 inches, wind-load demand in pounds, exterior structural steel stud screw pull-out, Fu/Fy, gauge, and pass/checkmark matrix fields. This meaningfully improves public bracket support load-table and shop-drawing/calculation-output shape evidence, but it still does not expose a filled project calculation, project elevation, selected bracket/anchor schedule, or governing project utilization.

The targeted returned-output search pass sharpened the facade gap rather than closing it. Public searches for returned Project Builder/static-calculation outputs, SFS/NVELOPE planning artifacts, Fixfast/Downer calculation examples, H&B/KWS engineering packages, Hilti/PROFIS facade-tied anchor reports, and planning/static-calculation attachments mostly returned general rainscreen guidance, already captured output-contract pages, or unrelated search noise. The Downer project archive adds a modest UK real-project/product-selection refinement: the public project index lists representative rainscreen projects, AC Hotel by Marriott at Manchester Salford Quays records Futural A1 with Downer DCS031 on a recladding project, and Broxbourne School records DCS031 bracket and rail use in Broxbourne, Hertfordshire. These pages are useful project-context and source-pack evidence when paired with the existing Downer static-calculation request form, but they still do not expose a returned calculation, elevation, pressure-zone map, selected fixing schedule, or governing utilization.

The practical benchmark path is now a task-owned redrawn source pack rather than waiting for a public returned project report. The pack should combine a small original/redrawn facade elevation with task-provided pressure zones, a selected support family, a bracket table excerpt, anchor/substrate capacity excerpts, a selected fixing schedule, and a calculation memo. Public sources can justify each artifact shape: SFS/NVELOPE and Downer/Fixfast define intake, setout, and returned-output semantics; WPS and Eurofox define calculation and utilization-table shape; KWS/H&B/Cascadia/Hilti/Ancon define bracket, clip, anchor, load-table, and adjacent support capacity fields. The benchmark should embed the normalized excerpts directly so the model reasons over a redistributable source pack instead of fetching live vendor documents or relying on inaccessible project reports.

This reduces the Project Builder intake/report-boundary and anchor-report-shape gap, but it still does not expose a public filled facade Project Builder PDF, real facade pressure-zone elevation, selected bracket/anchor schedule, or facade-tied governing utilization example.
