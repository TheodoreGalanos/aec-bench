# Treatment Aeration Power Package Gaps

## Source Gaps

- Need detailed public worked examples or design memoranda tying oxygen demand, SRT, MLSS/sludge age, alkalinity, diffuser/blower selection, and power in one traceable package. Ten States now supplies strong criteria but not a full worked project calculation.
- WEF and Metcalf & Eddy material is authoritative but generally not open.
- Need regional nutrient-removal and discharge-limit sources.
- Need public non-US utility/standards guidance for activated sludge, package plants, nutrient removal, and aeration energy.

## Data Gaps

- Real design reports are usually project-confidential.
- Public process diagrams often omit sizing assumptions.
- Equipment schedules rarely include enough blower efficiency, diffuser transfer, alpha/beta, operating pressure, and control data for power verification.
- EPA energy case studies ground the power/retrofit motivation, but they are not detailed blower selection calculations.

## Benchmark Gaps

- Need a process-type contract so the verifier knows which streams and calculations apply.
- Need unit normalization for mg/L, kg/d, MGD, m3/d, kWh/d, and oxygen transfer units.
- Need uncertainty handling for wastewater temperature, influent variability, and peak factors.
- Need source-pack fields for oxygen transfer assumptions, side-stream loads, minimum DO, altitude, critical temperature, RAS/WAS destination, and largest-unit-out redundancy.
