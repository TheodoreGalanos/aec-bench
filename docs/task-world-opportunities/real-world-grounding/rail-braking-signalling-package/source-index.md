# Rail Braking Signalling Package Source Index

## Current Chain Confidence

Medium-high:

rolling stock and alignment profile -> resistance/grade basis -> braking distance -> signal aspect sequence and sighting -> warning time and overlap/conflict protection -> signalling note.

The chain now has stronger current GB metadata via RSSB live standards, a strong public-practice anchor via IRSE training material, an EU braking-curve tool path via ERA, and concrete Australian owner-standard material from ARTC. ARTC materially improves the task-world evidence because it exposes public procedures and forms for braking distance calculations, signal sighting, overlap concepts, signal design process, signalling drawings, and configuration-controlled route artifacts. Full filled signal sighting records and live signal arrangement drawings are still not public fixtures, and rolling-stock braking assumptions remain operator-specific.
