# Civil Ground Retaining Interface Source Index

## Current Chain Confidence

The chain is realistic:

ground investigation -> interpreted soil/water/surcharge model -> earth pressures -> wall stability -> bearing and settlement -> civil/ground interface memo.

The public source base is now stronger than a single MSE-wall pathway. FHWA GEC 11 grounds MSE/reinforced-soil variants, FHWA GEC 7 grounds soil-nail walls, FHWA GEC 4 grounds anchored soldier-beam/lagging and ground-anchor systems, and WSDOT Chapter 15 grounds an owner/DOT workflow across abutments, retaining walls, reinforced slopes, temporary shoring, exploration, stability, drainage, and submittal review. The remaining weakness is not the design chain; it is public access to complete project-specific geotechnical reports, borehole logs, cross-sections, and final wall calculations in one reusable package.
