# Civil Ground Retaining Interface Gaps

## Source Gaps

- AASHTO LRFD and AS 4678 clause text is gated.
- Non-MSE public manual coverage is now stronger for soil nail and anchored wall systems through FHWA GEC 7 and GEC 4.
- Need public examples for cantilever, gravity, embedded pile, secant/tangent pile, and hybrid retaining systems.
- Need public local road authority examples, especially Australia/NZ and UK, and project-specific US DOT design memoranda beyond manual examples.
- Need public road-authority criteria or worked examples that translate AS 4678/AS 5100-style Australian practice into task-supplied benchmark criteria.

## Data Gaps

- Real geotechnical reports and borehole logs are often project-confidential.
- Public examples rarely include both interpreted parameters and final wall calculations in the same package.
- Construction staging and groundwater monitoring evidence are often omitted from simplified examples.
- FHWA/WSDOT manuals provide strong example and submittal shapes, but they do not replace project-specific boring logs, wall sections, groundwater records, and accepted final recommendations.

## Benchmark Gaps

- Need explicit uncertainty handling for ground parameters.
- Need visual/verifier support for reading wall height, retained slope, surcharge, and strata from cross-sections.
- Need regional switch logic because load/resistance formats differ materially.
- Need task-owned source-pack schemas for wall family, authority basis, wall geometry, exploration coverage, interpreted ground model, water/drainage assumptions, load cases, design/submittal review status, and proof/performance testing.
- Need verifier gates that can grade completeness and consistency of a submittal packet, not only scalar stability calculations.
