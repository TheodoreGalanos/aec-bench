# Earthing Arc Flash Package Gaps

## Source Gaps

- IEEE 1584, IEEE 1584.1, IEEE 1584.2, IEEE 80, and NFPA 70E full texts are gated.
- IEEE 80-2013 is now confirmed inactive-reserved with active project P80 visible, but final successor publication/status and open companion material for earthing grid design remain missing.
- IEEE 81-2025 is now confirmed as the active measurement guide for earth resistivity, ground impedance, touch/step voltage, and grounding-system integrity, but full test-method details remain gated.
- IEEE 1048-2016, 1048a-2021, and 1048b-2024 are now identified as current protective-grounding/equipotential-zone authority metadata, but full work-practice details remain gated.
- AS 2067:2016 now provides Australian high-voltage installation and earthing metadata, but full criteria remain gated.
- OSHA 1910.269 Appendix C now provides public US work-practice evidence for ground-potential gradients, step/touch potentials, equipotential zones, and protective-grounding clearing-time principles, but it is not a detailed grounding-grid design standard.
- Need IEC 60909, IEC 60479, ENA/utility earthing practice, detailed P80/IEEE 80 successor material, and additional regional grounding metadata.
- Ausgrid technical-library checks for NS116/earthing did not recover a stable public standard from this environment; treat NSW utility earthing criteria as not captured.

## Data Gaps

- Real arc flash studies are rarely public because they expose facility electrical details.
- Real protection settings and coordination curves are sensitive.
- Public SLD examples often lack enough impedance and device setting data for verification.
- This pass improved measurement/protective-grounding metadata but still did not find a clean redistributable grounding-grid worked example or protection-curve fixture; keep soil resistivity, grid geometry, current split, touch/step voltage, mesh voltage, measurement method, and clearing-time curves as explicit fixture targets.

## Benchmark Gaps

- Need a clear input schema for electrical study data extracted from drawings.
- Need controlled synthetic-but-realistic SLDs because real projects are hard to publish.
- Need standards-aware grading that does not leak gated formula text but still checks reasoning and evidence.
