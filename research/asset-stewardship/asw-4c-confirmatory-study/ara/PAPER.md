# Research continuation summary

ASW-4C executes the confirmatory study frozen in ASW-4A. It compares a
complete current station view with a structured handover. The comparison uses
32 matched pump-station histories and 64 model trajectories.

## Fixed study

- 16 H1 stable-inspected blocks.
- 16 H2 worsening-verification blocks.
- Two independent treatment branches per block.
- Hidden evaluation windows of three or four diagnostic periods.
- One fresh agent tenure per trajectory.
- The ASW-4A endpoint, paired analysis, uncertainty method, and coverage gates.
- No change to task reward.

The host must build each history with the promoted station data, physical
kernel, operating rules, durable run repository, and direct session. The H1
and H2 histories must have the same quantized current scalar reading. The two
treatment branches in each block must have the same current state and current
duties before treatment delivery.
